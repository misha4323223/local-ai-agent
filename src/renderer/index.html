              G4F — бесплатные модели без ключа. Запусти на ПК: pip install -U g4f, затем g4f api — современный interference-API живёт на порту 1337 (http://localhost:1337/v1), в старых сборках это порт 8080 (http://localhost:8080/v1) — если один не отвечает, поправь URL выше. Ключ НЕ нужен: поле можно оставить пустым (некоторые сборки принимают любую заглушку). Выбери провайдера в списке ниже (★ — стабильные, без входа): его типовые модели появятся сразу — нажми нужную, и «Провайдер:модель» подставится сам. Кнопка ▶ у провайдера — тест: что отвечает g4f и какие модели отдаёт, подробный лог уйдёт в правую панель «Консоль». Если g4f запущен, приложение само подтянет точный список моделей; кнопка ↻ у поля модели — на всякий случай. Провайдер передаётся g4f отдельным полем provider. Если провайдер отвечает «зарегистрируйтесь…» или молчит — просто выбери другого из списка. Инструменты агента работают через текстовый фолбэк — не все бесплатные провайдеры G4F поддерживают нативные вызовы инструментов.

Как это работает: агент правит свой код в src/ → прогоняет node --check → собирает бандл командой node scripts/make-ota.js → приложение подхватывает обновление и перезапускается. GitHub и пересборка EXE не нужны.
