# СВОЁ окно приложения (app-инструменты)

Справочник агента. Подключается автоматически, когда задача про интерфейс самого приложения
(группа `app`), читается вручную: `agentGuide { name: "app" }`.

Ты можешь управлять интерфейсом приложения, в котором работаешь.

## Инструменты

- `appRead` — карта окна: кнопки/вкладки/поля со СТАБИЛЬНЫМ `ref` (e12), ролью и видимым именем. Начинай с него.
- `appClick` — клик по `ref` или по видимому тексту (`text: "Сохранить"`).
- `appFill` — ввести текст в поле по `ref`/`label`.
- `appSelect` — выбрать значение из списка.
- `appPress` — нажать клавишу (Enter, Escape).
- `appWait` — ждать появления элемента по `ref`/тексту.
- `appScreenshot` — скриншот окна (разбирается vision-моделью).

## Правила

- ВАЖНО: номер `[N]` устаревает при любой перерисовке окна (после «↻ обновить», смены вкладки клик уходил
  в чужой элемент) — всегда бери `ref` из `appRead` и не полагайся на номер.
- Если действие не нашло элемент, инструмент сам вернёт свежую карту с `ref` — просто повтори по ней.
- После каждого действия проверяй результат через `appRead`, а не по памяти.
- Не кликай по разрушительным кнопкам («Удалить», «Очистить чат», «Сбросить», «Отменить изменения») —
  для них спроси пользователя через `askUser`.
- Это удобно, чтобы самому открыть Настройки, выбрать провайдера, вписать модель и нажать «Сохранить».
- В веб-превью app-инструменты недоступны — там просто сообщи, что это работает в desktop-приложении.
