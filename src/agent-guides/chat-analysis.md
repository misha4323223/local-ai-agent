# Анализ переписок: методология агента

> Применяется к любым диалогам: ВК (см. agent-guide:vk — как открыть диалог и
> прочитать историю), Telegram, экспортированные файлы чатов, письма, выгрузки.
> Цель: понять, с кем общается пользователь, что обсуждается, и подготовить
> почву для следующих шагов (в т.ч. коммерческих предложений клиентам).

## 0. Как получить текст переписки

- ВК: открой диалог `https://vk.com/im/convo/<id>`, дождись загрузки (2–5 с),
  затем `browserText`. Если история длинная и обрезается — листай вверх
  (`browserPress key: "PageUp"`), перечитывай `browserText` и собирай текст
  частями (2–4 прохода достаточно для понимания сути).
- Файл чата: `readFileLines` / `searchFile`, экспорт — прочитай и структурируй.
- Письма: прочитай цепочку, учитывай тему и адресата.

## 1. Определение человека (кто он)

Смотри на улики в тексте — не угадывай без оснований:

| Улика в переписке | Вывод |
|---|---|
| Обсуждают работу: задачи, дедлайны, проекты, отчёты, «на работе», коллеги | **Коллега / начальник / подчинённый** (уточни по тону и иерархии) |
| «дорогой/любимый/солнышко», семейные темы, быт, дети, планы на выходные | **Партнёр / супруг(а) / родственник** |
| Личное, встречи, «как дела», общие друзья, юмор | **Друг / знакомый** |
| Обсуждают услуги, цены, заказы, документы, договоры, сроки поставки, счета | **Клиент / покупатель / заказчик** |
| Предлагают товары/услуги, присылают прайсы, просят оплату | **Поставщик / продавец / подрядчик** |
| «Вы», имя-отчество, официальный тон, приветствие по должности | **Деловой контакт (формальный)** |
| Редко пишут, только по делу, просьбы | **Знакомый по делу / нетворк** |

Обращай внимание на: обращения («ты»/«вы», по имени/имени-отчеству), подписи,
упомянутые люди и места, эмодзи и тон, частоту и время сообщений.

## 2. Суть переписки (кратко)

Выдели за 2–4 предложения:
1. О чём разговор (тема/темы).
2. Что уже решено / договорено.
3. Что открыто / ждёт ответа.
4. Настроение и срочность (спокойно / напряжённо / горит).

## 3. Формат результата (всегда таблицей, если анализируешь несколько чатов)

```markdown
| Человек (профиль) | Кто он | Суть переписки | Важность | Следующий шаг |
|---|---|---|---|---|
| Имя, ссылка на профиль | Коллега | Обсуждали релиз: задачи X сделаны, ждём Y | Средняя | Подтвердить дедлайн Y |
| ... | ... | ... | ... | ... |
```

- **Важность**: высокая / средняя / низкая (деньги, сроки, конфликт → высокая).
- Если просили «проанализируй переписки» — собери таблицу по всем и добавь
  краткий вывод: кто из списка требует внимания и почему.

## 4. Клиенты: профиль и фундамент для КП

Когда в переписке виден клиент (обсуждают услугу/продукт/заказ), дополнительно
составь **профиль клиента**:

```markdown
### Профиль клиента: <Имя>
- Кто: <физлицо / компания, ниша, город — что видно из переписки>
- Потребность: <что он хочет решить своими словами>
- Что уже обсуждали: <услуги, объём, сроки, цены>
- Бюджет / сроки: <если упоминались — иначе «не упоминались»>
- Возражения / сомнения: <что его смущает>
- Тон общения: <деловой / дружеский / осторожный>
```

Затем предложи **фундамент для КП** (не пиши само КП без запроса):
- 2–4 пункта, которые стоит включить в КП (из его потребности и обсуждённого),
- какой следующий шаг логичен (отправить КП, позвонить, прислать пример работы),
- за что цепляться в разговоре (его слова как аргументы).

## 5. Правила

- Не выдумывай: если роль или детали не видны из переписки — пиши «не определено»
  и указывай, что уточнить.
- Не раскрывай личные данные в ответе сверх запрошенного (имена — можно,
  конфиденциальные детали — только по сути запроса).
- Если переписка на иностранном языке — переведи суть, но сохрани термины.
- Отвечай на русском, даже если переписка на другом языке.
